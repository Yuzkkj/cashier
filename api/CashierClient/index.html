CashierClient

This item only works when running on the client. Client

The client-side singleton for Cashier. Handles purchase prompts, gifting, item queries, and ownership state.

Types​

ItemType​

</>
type ItemType = "DevProduct" | "Gamepass" | "Semipass"

Determines the type of an item.

Item​

</>
interface Item {
name: string--

The unique name of the item

type: ItemType--

The type of the item ("DevProduct", "Gamepass", or "Semipass")

id: number--

The Roblox GamePass ID or Developer Product ID

giftId: number?--

The Developer Product ID used for gifting this item

}

Cashier:init()

getUnsentItems​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
CashierClient:getUnsentItems() → {[string]: number}--

A dictionary mapping item names to unsent gift counts

Fetches the list of unsent gifts owned by the local player that were not delivered (e.g. due to delivery failure).

local Cashier = require(path.to.Cashier).client

local unsentItems = Cashier:getUnsentItems()

for itemName, amount in unsentItems do
	print(`You have {amount} unsent {itemName}(s).`)
end

getAllItems​

</>
CashierClient:getAllItems() → {Item}--

An array containing all registered items

Returns an array of all registered items.

local Cashier = require(path.to.Cashier).client

local items = Cashier:getAllItems()

for _, item in items do
	print(item.name, item.type)
end

getItemPriceAsync​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
CashierClient:getItemPriceAsync(
itemName: string--

The name of the item to get the price of

) → number--

local price = Cashier:getItemPriceAsync("VIP")

print(`VIP costs {price} Robux`)

	print("You own the VIP gamepass.")
end

gift​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
CashierClient:gift(
recipientId: number,--

The UserId of the player to gift the item to

itemName: string--

The name of the item to gift

) → (
boolean,--

True if the gift was successfully initiated or delivered, false otherwise

string?--

An error message if the gift request failed

)

Sends a gift to another user by their UserId.

local Cashier = require(path.to.Cashier).client

local success, errMsg = Cashier:gift(123456, "VIP")

if not success then
	warn("Gifting failed:", errMsg)
end

onGiftReceived​

</>
CashierClient:onGiftReceived(
giftData: GiftData--

Information about the received gift

) → ()

Types

​

interface GiftData {
item: string--

The name of the gifted item

from: number--

The UserId of the player who sent the gift

}

An overridable callback invoked when the local player receives a gift. Can be overridden to display custom UI or notifications.

local Cashier = require(path.to.Cashier).client

function Cashier:onGiftReceived(giftData)
	print(`You received {giftData.item} from UserId {giftData.from}.`)
end
